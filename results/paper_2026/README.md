# Paper 2026 Reproduction Outputs

This directory contains one complete set of outputs used to reproduce the paper figures from the current implementation.

Tracked runs:

- `paper_fig2_cpmg/cpmg_fig2_20260721-044956`: CPMG state-fidelity sweep for Figure 2.
- `paper_fig3_rb_tau_sweep/rb_tau_20260721-045718`: fixed-depth RB survival sweep for Figure 3.
- `paper_fig4_fig5_rb_decay/rb_decay_20260721-053908`: RB decay curves and fit statistics for Figures 4 and 5.

Each run directory includes its configuration, provenance, raw arrays where applicable, postprocessed tables, summaries, and generated figures.

Other historical or exploratory result directories are intentionally not tracked.
